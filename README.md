# Bili Dolby Bridge

Chrome/Edge Manifest V3 extension that bridges Bilibili's native player to its
Dolby Atmos audio track (`30250`).

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 保持 Bilibili 登录，并打开有杜比音轨的视频。
5. 更新扩展时，点击扩展卡片上的“重新加载”。
6. 在扩展的“详情 > 扩展程序选项”中查看开关与状态。

页面右下角徽标会显示真实状态：只有网络请求实际选中 `30250` 时才显示
`杜比 30250`，不应把“偏好已写入”当作 E-AC-3 播放成功的证据。

更新主世界脚本时，请先移除现有扩展，再重新选择本目录。只点击“重新加载”
或只覆盖文件，通常不会让正在运行的扩展立即采用新脚本。

页面右下角的状态按钮可查看当前结果；点击它会立即关闭扩展并移除按钮。

## 行为

- 只在 `https://www.bilibili.com/*` 页面生效。
- 复用当前 Bilibili 登录态，不保存或上传账号凭据。
- 不绕过大会员、版权、地区或账号权限。
- 优先激活 Bilibili 原生音效按钮，并写入播放器自己的杜比偏好，使后续视频继续优先杜比。
- 页面会以实际 `30250` 媒体请求作为当前音轨的成功信号；仅写入偏好不再显示为已播放杜比。
- 若底栏出现杜比按钮、但接口没有返回 `dash.dolby.audio`，状态页会提示“等待音源”，并保留登录、会员、版权和地区限制。

常见情况：杜比按钮提示“开启杜比全景声大会员”，但没有实际音轨。这表示
Bilibili 已识别浏览器能力，但账号或视频权限不允许返回 `30250`；扩展不会
绕过该限制。

## 验收

打开一个确认包含杜比音轨的视频，扩展应记录
`30250` 音轨；选项页的“最近音轨”应为 `30250`。实际多声道输出还取决于
Windows、声卡、扬声器和耳机设置。

如果页面仍在播放 Hi-Res，请在清晰度菜单中先切到其他档位，再切回原档位，
让播放器重新解析音轨；也可以关闭并重新打开音效按钮。

如果 Chrome、Edge 或 Windows 没有可用的 E-AC-3 解码链路，即使页面显示支持，
杜比音轨也可能无声。此时关闭扩展即可恢复普通音轨。

安装或更新扩展后需要刷新已经打开的 B 站视频页；Chrome 不会把内容脚本自动注入到旧标签。

若扩展错误页仍显示 `DataCloneError`，请先点击“全部清除”，再确认版本为
`0.3.0` 或更高并刷新 B 站页面。
